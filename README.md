# AutoStatus Workshop Pro 🚗💨

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

Mobile-first PWA for Greek Auto Repair Workshops (Συνεργεία Αυτοκινήτων).

## Features
- **10-Second Intake:** Camera plate scanner (OCR), auto-lookup, instant check-in.
- **AADE Digital Registry Compliance:** Official myDATA REST API integration (Απόφαση Α.1057/2025).
- **Driver Live Tracking & Damage Approvals:** Real-time status with 1-click photo damage approval (`wa.me` & `viber://forward`).
- **Tactile Grease-Friendly UI:** Designed for workshop mechanics.
- **Automated Backup & Disaster Recovery:** 1-Click ZIP exports and encrypted snapshots.

## 1-Click Cloud Deployment (Render.com)
1. Fork or clone this repository.
2. Click the **Deploy to Render** button above or connect your repository on [dashboard.render.com](https://dashboard.render.com).
3. Render will automatically detect `render.yaml` and launch the app with free SSL HTTPS.
